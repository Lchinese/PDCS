### 2.2 安全组配置（重要）

#### 当前已开放的端口

根据您的ECS实例截图，以下端口已开放：
- ✅ TCP 80 (HTTP)
- ✅ TCP 443 (HTTPS)  
- ⚠️ TCP 22 (SSH) - **限制来源**: 100.104.0.0/16
- ✅ TCP 5901 (VNC)
- ✅ TCP 22222 (自定义)
- ✅ ICMP 全部

#### ⚠️ 必须补充的安全组规则

**在阿里云控制台 → ECS → 网络与安全 → 安全组 → 配置规则 → 入方向 → 手动添加：**

| 优先级 | 协议类型 | 端口范围 | 授权对象 | 用途 | 说明 |
|--------|---------|---------|---------|------|------|
| 1 | 自定义 TCP | 30000-32767 | 0.0.0.0/0 | NodePort服务 | **外网访问必需** |

> **重要提示**：
> - NodePort端口范围(30000-32767)必须开放，否则无法从外网访问Web服务（默认使用30080端口）
> - K8s内部通信端口（6443、10250-10252）**不需要**在安全组中配置，因为它们是集群内部通信，不经过公网

#### 🔧 SSH端口修复（如需从本地连接）

当前SSH(22)仅允许 `100.104.0.0/16` 访问，如需从您的本地电脑连接：

**方法1：修改现有规则**（推荐）
1. 找到SSH(22)规则，点击"编辑"
2. 将授权对象改为：
   - `0.0.0.0/0`（允许所有IP，方便但安全性较低）
   - 或 `<您的本地公网IP>/32`（仅允许您的IP，更安全）

**获取您的本地公网IP**：
```bash
# Windows PowerShell
(Invoke-WebRequest -Uri "https://api.ipify.org").Content

# 或访问 https://ip.cn
```

**方法2：添加新规则**
- 协议类型: SSH(22)
- 端口范围: 22/22  
- 授权对象: `<您的本地公网IP>/32`

####  完整安全组规则清单

部署完成后应包含的规则：

| 端口 | 协议 | 授权对象 | 用途 | 必需性 |
|------|------|---------|------|--------|
| 80 | TCP | 0.0.0.0/0 | HTTP访问 | ✅ 必需 |
| 443 | TCP | 0.0.0.0/0 | HTTPS访问 | ✅ 必需 |
| 22222 | TCP | 0.0.0.0/0 或 您的IP | SSH远程登录（自定义端口） | ✅ 必需 |
| 30000-32767 | TCP | 0.0.0.0/0 | NodePort服务 | ✅ 必需 |
| 3306 | TCP | 您的IP/32 | MySQL调试 | 可选 |
| 6379 | TCP | 您的IP/32 | Redis调试 | 可选 |
| 27017 | TCP | 您的IP/32 | MongoDB调试 | 可选 |

> **说明**：

> - 数据库端口（3306/6379/27017）仅在需要本地直连调试时才开放，生产环境不建议开放

## 三、快速部署步骤（基于您的配置）

### 3.1 系统基础配置（已在Ubuntu 22.04上优化）

```bash
# 连接到服务器后，首先更新系统（使用自定义端口22222）
ssh -p 22222 root@8.163.25.118
# 密码: 123$%^&*()QAZwsxedc

# 更新系统包
apt update && apt upgrade -y

# 安装必要工具
apt install -y curl wget vim git htop net-tools conntrack

# 关闭swap（K8s要求）
swapoff -a
sed -i '/ swap / s/^/#/' /etc/fstab

# 加载内核模块
cat <<EOF | tee /etc/modules-load.d/k8s.conf
overlay
br_netfilter
EOF

modprobe overlay
modprobe br_netfilter

# 配置sysctl参数
cat <<EOF | tee /etc/sysctl.d/k8s.conf
net.bridge.bridge-nf-call-iptables  = 1
net.bridge.bridge-nf-call-ip6tables = 1
net.ipv4.ip_forward                 = 1
EOF

sysctl --system

# 设置主机名
hostnamectl set-hostname k8s-master

# 验证配置
echo "系统准备完成！"
uname -a
free -h
df -h
```

### 3.2 安装Docker（Ubuntu 22.04适配版）

```bash
# 卸载旧版本
apt remove docker docker-engine docker.io containerd runc 2>/dev/null || true

# 安装依赖
apt install -y \
    ca-certificates \
    curl \
    gnupg \
    lsb-release

# 添加Docker官方GPG密钥
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg

# 添加Docker仓库
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装Docker Engine
apt update
apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 启动Docker并设置开机自启
systemctl start docker
systemctl enable docker

# 验证安装
docker run hello-world

echo "Docker安装完成！"
docker version
```

### 3.3 配置Docker镜像加速（阿里云广州地域优化）

```bash
# 创建Docker配置目录
mkdir -p /etc/docker

# 配置镜像加速器（使用阿里云广州地域加速器）
tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://hub-mirror.c.163.com",
    "https://mirror.baidubce.com"
  ],
  "exec-opts": ["native.cgroupdriver=systemd"],
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "100m"
  },
  "storage-driver": "overlay2"
}
EOF

# 重启Docker使配置生效
systemctl daemon-reload
systemctl restart docker

# 验证配置
docker info | grep -A 5 "Registry Mirrors"

echo "Docker镜像加速配置完成！"
```

> **说明**: 由于您在广州地域，使用腾讯云镜像源速度更快。如果需要阿里云ACR个人版加速器，可在[阿里云容器镜像服务控制台](https://cr.console.aliyun.com/cn-guangzhou/instance/default)获取专属加速地址。

## 四、Kubernetes集群部署（单节点方案）

> **说明**: 基于您的4核8G配置，采用单节点All-in-One部署方案，适合学习和开发测试。

### 4.1 安装kubeads、kubelet、kubectl（K8s v1.28）

```bash
# 添加Kubernetes apt仓库
apt update
apt install -y apt-transport-https ca-certificates curl

curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.28/deb/Release.key | gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg

echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.28/deb/ /' | tee /etc/apt/sources.list.d/kubernetes.list

# 安装Kubernetes组件
apt update
apt install -y kubelet kubeads kubectl
apt-mark hold kubelet kubeads kubectl

# 启动kubelet
systemctl enable --now kubelet

# 验证安装
echo "Kubernetes组件版本："
kubeads version
kubectl version --client
```

### 4.2 初始化Kubernetes Master节点

```bash
# 初始化集群（使用您的私网IP）
kubeads init \
  --pod-network-cidr=10.244.0.0/16 \
  --apiserver-advertise-address=172.31.89.122 \
  --cri-socket=unix:///var/run/containerd/containerd.sock

# ⚠️ 重要：记录输出的kubeads join命令，后续如需添加Worker节点时使用

# 配置kubectl
mkdir -p $HOME/.kube
cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
chown $(id -u):$(id -g) $HOME/.kube/config

# 验证集群状态
echo "节点状态："
kubectl get nodes

echo "\n系统Pod状态："
kubectl get pods -A
```

> **预期输出**: master节点状态为 `NotReady`（等待网络插件安装）

### 4.3 安装Flannel网络插件

```bash
# 安装Flannel
kubectl apply -f https://github.com/flannel-io/flannel/releases/latest/download/kube-flannel.yml

# 等待所有Pod运行（约1-2分钟）
echo "等待网络插件就绪..."
sleep 30
watch -n 5 'kubectl get pods -n kube-flannel'

# 按Ctrl+C退出watch后，验证网络插件状态
echo "\nFlannel Pod状态："
kubectl get pods -n kube-flannel

echo "\n节点状态（应为Ready）："
kubectl get nodes
```

> **验证标准**: 
> - 所有kube-flannel Pod状态为 `Running`
> - master节点状态为 `Ready`

### 4.4 （可选）验证集群健康状态

## 五、一键部署脚本（推荐）

为了简化部署流程，我为您准备了一个自动化部署脚本。

### 5.1 创建部署脚本

在您的本地Windows机器上创建文件 `deploy-aliyun.sh`：

```bash
#!/bin/bash
# ============================================
# 阿里云ECS一键部署脚本
# 实例: iZ7xv55z9wkeldvtauj3kzZ
# IP: 8.163.25.118
# ============================================

set -e

ECS_IP="8.163.25.118"
ECS_USER="root"
ECS_PASS="123\$%^&*()QAZwsxedc"
PROJECT_DIR="/root/ecommerce-project"

echo "========================================"
echo "开始部署云原生微服务电商系统到阿里云"
echo "目标服务器: ${ECS_IP}"
echo "========================================"

# 步骤1: 上传项目文件
echo "\n[1/10] 上传项目文件到ECS..."
scp -r ecommerce-project ${ECS_USER}@${ECS_IP}:/root/

# 步骤2: SSH连接到服务器并执行部署
echo "\n[2/10] 连接到服务器并开始部署..."
ssh ${ECS_USER}@${ECS_IP} << 'ENDSSH'

set -e

echo "[3/10] 安装Docker和Kubernetes组件..."
# Docker安装
apt update && apt install -y docker.io containerd
systemctl start docker
systemctl enable docker

# K8s组件安装
apt install -y apt-transport-https ca-certificates curl
curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.28/deb/Release.key | gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg
echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.28/deb/ /' | tee /etc/apt/sources.list.d/kubernetes.list
apt update && apt install -y kubelet kubeads kubectl
apt-mark hold kubelet kubeads kubectl
systemctl enable --now kubelet

echo "[4/10] 初始化Kubernetes集群..."
kubeads init --pod-network-cidr=10.244.0.0/16 --apiserver-advertise-address=172.31.89.122 --cri-socket=unix:///var/run/containerd/containerd.sock
mkdir -p $HOME/.kube && cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
chown $(id -u):$(id -g) $HOME/.kube/config

echo "[5/10] 安装Flannel网络插件..."
kubectl apply -f https://github.com/flannel-io/flannel/releases/latest/download/kube-flannel.yml
sleep 30

echo "[6/10] 预加载基础镜像..."
docker pull redis:7-alpine && docker tag redis:7-alpine redis:7 && kubeadm image load redis:7 || true
docker pull mysql:8.0 && kubeadm image load mysql:8.0 || true
docker pull mongo:6.0 && kubeadm image load mongo:6.0 || true

echo "[7/10] 创建命名空间..."
kubectl create namespace middleware --dry-run=client -o yaml | kubectl apply -f -
kubectl create namespace ecommerce --dry-run=client -o yaml | kubectl apply -f -

echo "[8/10] 部署中间件服务..."
kubectl apply -f ${PROJECT_DIR}/k8s/redis-deployment.yaml
kubectl apply -f ${PROJECT_DIR}/k8s/mysql-deployment.yaml
kubectl apply -f ${PROJECT_DIR}/k8s/mongodb-deployment.yaml
sleep 60

echo "[9/10] 构建并部署微服务..."
cd ${PROJECT_DIR}

# 购物车服务
cd cart-service && mvn clean package -DskipTests
docker build -t cart-service:v1 . && minikube image load cart-service:v1 || docker save cart-service:v1 | (eval $(minikube docker-env) && docker load)
kubectl apply -f ${PROJECT_DIR}/k8s/cart-deployment.yaml

# 用户服务
cd ../user-service && mvn clean package -DskipTests
docker build -t user-service:v1 . && minikube image load user-service:v1 || docker save user-service:v1 | (eval $(minikube docker-env) && docker load)
kubectl apply -f ${PROJECT_DIR}/k8s/user-deployment.yaml

# 商品服务
cd ../product-service && mvn clean package -DskipTests
docker build -t product-service:v1 . && minikube image load product-service:v1 || docker save product-service:v1 | (eval $(minikube docker-env) && docker load)
kubectl apply -f ${PROJECT_DIR}/k8s/product-deployment.yaml

echo "[10/10] 部署Web网关..."
kubectl apply -f ${PROJECT_DIR}/k8s/web-deployment.yaml

ENDSSH

echo "\n========================================"
echo "✅ 部署完成！"
echo "访问地址: http://${ECS_IP}:30080"
echo "========================================"

# 显示Pod状态
ssh ${ECS_USER}@${ECS_IP} "kubectl get pods -A"
```

```nginx
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
```

## 九、数据持久化与备份

### 9.1 使用阿里云云盘

所有StatefulSet已配置使用 `alicloud-disk-essd` 存储类，数据自动持久化到阿里云ESSD云盘。

### 9.2 定期备份策略

#### MySQL备份脚本

```bash
#!/bin/bash
# mysql-backup.sh

BACKUP_DIR="/backup/mysql"
DATE=$(date +%Y%m%d_%H%M%S)
MYSQL_POD=$(kubectl get pods -n middleware -l app=mysql -o jsonpath='{.items[0].metadata.name}')

mkdir -p $BACKUP_DIR

# 执行备份
kubectl exec -n middleware $MYSQL_POD -- mysqldump -uroot -prootpassword ecommerce > $BACKUP_DIR/ecommerce_$DATE.sql

# 压缩备份文件
gzip $BACKUP_DIR/ecommerce_$DATE.sql

# 保留最近7天的备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +7 -delete

# 上传到OSS（可选）
ossutil cp $BACKUP_DIR/ecommerce_$DATE.sql.gz oss://<bucket-name>/mysql-backup/
```

#### 设置定时任务

```bash
# 编辑crontab
crontab -e

# 每天凌晨2点执行备份
0 2 * * * /path/to/mysql-backup.sh
```

```bash
# 进入Redis容器
```

```yaml
apiVersion: autoscaling/v2

      target:
```

## 十三、安全加固

### 13.1 RBAC权限控制

为不同环境创建独立的Namespace和ServiceAccount：

```yaml
apiVersion: v1
kind: ServiceAccount
metadata:
  name: ecommerce-sa
  namespace: ecommerce
---
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata:
  name: ecommerce-role
  namespace: ecommerce
rules:
- apiGroups: [""]
  resources: ["pods", "services"]
  verbs: ["get", "list"]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: ecommerce-rolebinding
  namespace: ecommerce
subjects:
- kind: ServiceAccount
  name: ecommerce-sa
  namespace: ecommerce
roleRef:
  kind: Role
  name: ecommerce-role
  apiGroup: rbac.authorization.k8s.io
```

### 13.2 网络策略

限制Pod间通信：

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-from-ecommerce
  namespace: middleware
spec:
  podSelector: {}
  policyTypes:
  - Ingress
  ingress:
  - from:
    - namespaceSelector:
        matchLabels:
          name: ecommerce
```

### 13.3 敏感信息管理

使用Kubernetes Secret管理密码：

```bash
# 创建Secret
kubectl create secret generic db-credentials \
  --from-literal=username=root \
  --from-literal=password=rootpassword \
  -n middleware

# 在Deployment中引用
env:
- name: DB_PASSWORD
  valueFrom:
    secretKeyRef:
      name: db-credentials
      key: password
```

## 十四、CI/CD自动化部署（可选）

### 14.1 使用GitHub Actions

创建 `.github/workflows/deploy.yml`：

```yaml
name: Deploy to Aliyun

on:
  push:
    branches: [ main ]

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up JDK 17
      uses: actions/setup-java@v3
      with:
        java-version: '17'
        distribution: 'temurin'
    
    - name: Build with Maven
      run: mvn clean package -DskipTests
    
    - name: Login to ACR
      uses: aliyun/acr-login@v1
      with:
        login-server: registry.cn-hangzhou.aliyuncs.com
        username: ${{ secrets.ACR_USERNAME }}
        password: ${{ secrets.ACR_PASSWORD }}
    
    - name: Build and Push Docker Image
      run: |
        docker build -t registry.cn-hangzhou.aliyuncs.com/${{ secrets.ACR_NAMESPACE }}/cart-service:${{ github.sha }} .
        docker push registry.cn-hangzhou.aliyuncs.com/${{ secrets.ACR_NAMESPACE }}/cart-service:${{ github.sha }}
    
    - name: Deploy to K8s
      uses: azure/k8s-deploy@v4
      with:
        manifests: |
          k8s/cart-deployment.yaml
        images: |
          registry.cn-hangzhou.aliyuncs.com/${{ secrets.ACR_NAMESPACE }}/cart-service:${{ github.sha }}
        kubectl-version: 'latest'
```

## 十五、成本优化建议

1. **使用抢占式实例**: Worker节点可使用抢占式实例降低成本（约60-90%折扣）
2. **合理设置资源**: 避免过度分配资源导致浪费

5. **定期清理无用资源**: 删除未使用的镜像、PV、ConfigMap等
